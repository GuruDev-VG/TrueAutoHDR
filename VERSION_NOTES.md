# TrueAuto HDR 1.5.0 reconstructed canonical source

This tree was reconstructed from the last complete in-chat 1.3.2 source and the subsequently agreed 1.4.x specifications.

It includes the Stable 1.5.0 UI redesign, Steam selected-game artwork cache, HDR10+ Gaming metadata/identity inheritance, and per-game display recovery. Stable and Canary update package paths are isolated.

The reconstruction environment did not contain the .NET SDK, so source-level validation was performed here but the Windows Release build must be compiled on a Windows machine with .NET 8 before publication.
