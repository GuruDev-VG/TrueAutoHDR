# TrueAuto HDR 1.5.1

## Fixes

- Fixed Game Manager layout becoming cramped after Windows reboot or sign-in.
- Removed an extra WinForms autoscale pass that could double-scale the UI.
- Improved Per-Monitor V2 DPI behavior.
- Added responsive sizing for the header, search box, Refresh button, Discover & Verify controls, selected-game panel, and footer.
- Added safe window sizing against the current monitor working area.
- Improved behavior at 125% and 150% Windows display scaling.
- Preserved the 1.5.0 Game Manager redesign, Steam artwork, HDR10+ Gaming support, and Display Recovery.
