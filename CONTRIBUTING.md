# Contributing to TrueAuto HDR

Thanks for helping improve TrueAuto HDR.

## Bug reports

Please include the TrueAuto HDR version, Windows version, game/storefront, display configuration when relevant, reproduction steps, expected behavior, actual behavior, and useful log lines.

Do not post credentials, tokens, personal information, or unrelated full system logs.

## Pull requests

Keep changes focused. Explain what problem the change solves and how you tested it. Changes affecting HDR switching, startup behavior, game identity matching, database updates, or self-updating should include clear regression-testing notes.



The standard is the result: contributors are responsible for understanding, reviewing, testing, and being able to explain the code they submit. Do not submit large unreviewed generated changes.

Technical criticism of AI-generated code is welcome and encouraged. Repetitive arguments about whether AI should be used at all are outside the scope of this repository.

## Canary

Experimental changes should normally be tested through the Canary channel before promotion to Stable when they have meaningful regression risk.
